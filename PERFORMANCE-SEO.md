# Image SEO and Core Web Vitals audit

## Scope

This pass reviewed image components, CSS background images, responsive sizing, loading priority, font delivery and client-side work across the public site. The visual layouts, crops and animation style were preserved.

## Changes made

### LCP and responsive delivery

- Replaced the homepage hero's JavaScript viewport check and raw animated image with responsive `<picture>` output generated by Next.js.
- The existing portrait source remains the mobile crop and the existing landscape source remains the desktop crop.
- The hero has intrinsic dimensions, responsive `srcset` values, `sizes="100vw"` and high fetch priority.
- Only genuine above-the-fold hero images retain priority treatment. The navigation logo is no longer eagerly preloaded.

### CLS prevention

- All rendered `next/image` instances use intrinsic dimensions or `fill` inside an explicitly sized/aspect-ratio container.
- Added missing responsive `sizes` hints to homepage feature, food and function imagery.
- Image containers retain their existing fixed heights or aspect ratios, reserving space before media loads.

### Alt text

- Replaced empty or generic alt text on homepage venue, outdoor, dining, function and entertainment images.
- Replaced repetitive keyword-heavy food-carousel descriptions with concise descriptions of the visible dishes.
- Removed unsupported promotional wording from image descriptions.
- Menu-page images now use clear page-level descriptions rather than promotional copy.

### Oversized active source images

Next.js still creates device-appropriate variants at request time. The derivatives reduce repository, build and server image-processing overhead while retaining high-resolution masters.

### INP and JavaScript

- Deferred the third-party Instagram widget until its section approaches the viewport.
- Removed its permanent one-second polling interval.
- The temporary DOM observer now disconnects after completing its task.
- Existing Swiper and motion interactions were retained because they are part of the current design. They remain the largest client-side interaction cost and should be re-measured before any visual simplification is considered.

### Fonts and render blocking

- Removed the render-blocking Google Fonts CSS `@import`.
- Aleo and Lexend Deca now use `next/font`, which self-hosts and preloads the required font files through Next.js.

## Loading policy

- Homepage, contact, venue and function hero images are the only images intentionally prioritised.
- Below-the-fold `next/image` content uses the framework's default lazy loading.
- Responsive `sizes` values prevent mobile devices from selecting unnecessarily large desktop variants.

## Unused and retained assets

- Large original JPEG files are retained as recoverable masters but are no longer referenced by the optimised page components.
- The repository contains additional large gallery and legacy promotional assets that are not referenced by current public routes. They were not deleted because asset removal was outside this task and could affect unpublished workflows.
- The former `spaces/whisky-lounge.jpg` asset remains on disk but is not referenced by current `/spaces` content.

## Future measurement

Run Lighthouse or WebPageTest against the deployed production domain after release. CDN behaviour, third-party widget timing and real-user network conditions cannot be fully represented by a local production build.
