# Final browser check after deployment

Browser automation is unavailable in this environment. After deployment, test these in a real desktop and mobile browser:

1. Homepage: hero copy is legible over the image; the seven quick links work; navigation opens, closes and remains keyboard accessible.
2. Food and Drinks: headings, FAQ sections, menu links and the OpenTable booking links work.
3. Functions: the page is visible immediately (no menu overlay), space capacity cards are readable, all links work, and a valid function enquiry delivers an email.
4. Spaces: all images load; capacity cards link to the function-enquiry section.
5. What's On: swipe cards work on touch devices; confirm every displayed time and offer with the venue; OpenTable and menus links work.
6. Contact: map, call, email, booking and function-enquiry actions work on mobile; submit a safe test contact enquiry.
7. Menus: breadcrumb display, slider controls and each menu PDF download work on desktop and mobile.
8. Test `/club` and `/function-space` redirect once only; test an invalid URL renders the branded 404.
9. Check no horizontal scrolling, clipped fixed download buttons, console errors, image distortion or focus-trap problems occur at 320px, 768px and desktop widths.
